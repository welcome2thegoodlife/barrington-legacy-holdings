## Adding a New Collection

1. Add the mockup image and a collection document to this folder.
2. Record the historical lineage, attribution, and review checklist (see the Historical Figure Merchandise Rule in `docs/01-black-box/EPISODE-ARCHITECTURE.md`).
3. Add the collection to the table above.
4. Add an entry to `CHANGELOG.md`.

Every product should answer: *What does this help the next creator do?*
